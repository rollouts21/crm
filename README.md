# Mini CRM — Laravel 12 (Blade + Bootstrap)

Mini CRM — backend-ориентированная CRM-система для малого бизнеса, разработанная на Laravel 12.
Проект создан как учебный, но с упором на **реальную бизнес-логику, архитектуру и качество кода**, а не просто CRUD.

---

## 📌 Назначение проекта

Система предназначена для:
- управления клиентами (лидами)
- ведения сделок и их статусов
- контроля задач и напоминаний
- отслеживания действий пользователей
- получения базовой аналитики

Проект демонстрирует подходы к построению backend-приложений на Laravel и может служить портфолио-проектом.

---

## ✨ Основной функционал

### 👥 Клиенты (Leads)
- создание, редактирование, удаление (soft delete)
- статусы клиентов
- источники лидов
- автозаполнение даты последнего контакта

### 💼 Сделки
- привязка к клиенту
- статусы: `new`, `in_progress`, `won`, `lost`
- бизнес-правила закрытия сделки

### ✅ Задачи
- приоритеты
- отметка выполнения
- определение просроченных задач

### 🔎 Поиск и фильтрация
- поиск по имени и телефону
- фильтрация по статусам
- сортировка и пагинация

### 🔐 Роли и доступы
- **Admin** — полный доступ
- **Manager** — доступ только к своим данным
- разграничение прав через Policies

### 📜 Аудит действий
- логирование ключевых действий пользователей
- история изменений сущностей

## 🧭 Архитектура

Проект построен с упором на разделение ответственности:

- тонкие контроллеры
- бизнес-логика вынесена в Service / Action классы
- валидация через FormRequest
- контроль доступа через Policies
- единое доменное ядро, независимое от UI

## 🚀 Установка и запуск (локально)

### Требования
- PHP 8.4+
- Composer
- Node.js + npm
- PostgreSQL или MySQL

### Установка
```bash
git clone https://github.com/rollouts21/crm.git
cd crm

composer install
npm install
npm run build

cp .env.example .env
php artisan key:generate
php artisan migrate --seed
```

### Запуск
```bash
php artisan serve
```

Открыть в браузере:
http://127.0.0.1:8000

---

## 🐳 Запуск через Docker

Проект поддерживает запуск через Docker (PHP-FPM + Nginx + PostgreSQL + Vite).

### Требования
- Docker
- Docker Compose

### Запуск
```bash
docker compose up -d --build
```

После запуска:
- приложение: http://localhost:8080
- Vite dev server: http://localhost:5173

Миграции и установка зависимостей выполняются автоматически при старте контейнеров.
